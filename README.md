# O que é um banco de dados?

Com o conhecimento que tenho, tentei reproduzir a ideia do que é um banco de dados.

Fiz o repositório apenas para brincar com a ideia de montar um arquivo binário padronizado para guardar dados binários, ele guarda listas de binários e sua aplicação é responsável por interpretar a natureza dos dados.
Não fiz para uso em produção, não recomendo e não está pronto para isso.

Para qualquer um que quiser entender a ideia e desenvolver algo a partir disso fiquem a vontades para fazer *pull requests* ou *forks*.
